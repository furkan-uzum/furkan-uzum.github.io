# furkanuzum.com — TradeLab

[TradeLab](https://github.com/furkan-uzum/TradeLab) projesinin tanıtım sayfası. Sayfa GitHub Pages üzerinde statik olarak yayınlanır; alan adı `CNAME` dosyasında.

- "Canlı piyasa" tablosu, Binance'in herkese açık `miniTicker` akışına ziyaretçinin tarayıcısından doğrudan bağlanır. Sunucu gerekmez. Bazı bölgelerde Binance erişime kapalı olabilir; o durumda sayfa "Bağlantı yok" gösterir ve yeniden dener.
- TradeLab uygulaması (backend + işlem ekranı) hazır olduğunda bu adreste yayınlanacak.
